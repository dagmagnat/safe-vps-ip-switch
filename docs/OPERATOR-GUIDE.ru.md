# Краткая инструкция оператору

Эта памятка рассчитана на сотрудника, который раньше не менял IP на Linux-сервере.

## Перед началом

1. Убедитесь, что новый IPv4 уже привязан к VPS в панели хостинга.
2. Старый IP пока не удаляйте.
3. Подключитесь к VPS по SSH.
4. Выполните:

```bash
sudo zamenaip
```

## Что нажимать

- `1` — посмотреть текущий IP и проверить доступ.
- `2` — заменить основной IPv4.
- `3` — проверить сервер после перезагрузки.
- `4` — резервные копии и восстановление.
- `5` — проверить сайт и DNS.
- `6` — язык и настройки.
- `0` — назад.

## Замена IP

1. Нажмите `2`.
2. Выберите нужный IPv4 из списка.
3. Если адреса нет — выберите ручной ввод и введите IPv4.
4. Дождитесь проверки IP и шлюза.
5. Проверьте план на экране.
6. Подтвердите создание backup.
7. При запуске `netplan try` **не закрывайте SSH**.
8. Если сеть продолжает работать, подтвердите Netplan клавишей Enter.
9. Дождитесь сообщения об успешной проверке.
10. При необходимости согласитесь на reboot.

## После reboot

Снова подключитесь к новому IP и выполните:

```bash
sudo zamenaip
```

Выберите `3`.

Если проверка успешна, можно сначала **отвязать** старый IP в панели провайдера. После этого снова проверьте SSH и сайт. Только затем удаляйте старый IP окончательно.

## Если что-то пошло не так

Запустите:

```bash
sudo zamenaip
```

Выберите `4` → восстановление резервной копии → выберите последнюю рабочую копию.

Перед восстановлением программа сама создаст ещё одну страховочную копию.

## Обновление программы

Если в главном меню доступен пункт **«Обновить ZAMENAIP»**, используйте его или команду:

```bash
sudo zamenaip update
```

Если установлена очень старая версия и команды `update` ещё нет, выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/dagmagnat/safe-vps-ip-switch/main/install.sh | sudo bash -s -- --no-start
```

Это обновляет саму программу и исправляет команду `zamenaip`, но не меняет текущий IP/Netplan.
