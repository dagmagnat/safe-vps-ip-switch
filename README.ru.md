# safe-vps-ip-switch

Безопасный интерактивный Bash-скрипт для смены основного публичного IPv4 на Ubuntu VPS с **Netplan**.

Рекомендуемое имя репозитория: **`dagmagnat/safe-vps-ip-switch`**.

## Что делает скрипт

Скрипт построен так, чтобы максимально снизить риск потерять SSH-доступ:

- показывает текущий публичный IPv4, интерфейс и шлюз;
- просит указать новый IPv4;
- для `/24` сам предлагает шлюз вида `X.Y.Z.1`, но позволяет изменить его;
- создаёт резервную копию `/etc/netplan` и `/etc/nginx`;
- временно добавляет новый IP и проверяет исходящий доступ именно с него;
- создаёт отдельный Netplan-файл вместо правки cloud-init конфигов;
- запускает `netplan generate`;
- если в активном nginx уже есть `proxy_bind OLD_IP;`, меняет его на новый IP;
- запускает `nginx -t`;
- применяет сеть через `netplan try --timeout 120`, поэтому неподтверждённая нерабочая конфигурация должна откатиться автоматически;
- проверяет внешний IP и source IP маршрута;
- умеет проверять сайт;
- умеет проверять конфигурацию после перезагрузки;
- умеет откатываться на резервную копию.

**Скрипт никогда не удаляет старый IP в панели хостинга.** Это нужно делать вручную только после перезагрузки и успешной команды `verify`.

## Требования

- Ubuntu 22.04 / 24.04 или другая система с Netplan;
- root-доступ;
- `curl`;
- `python3`;
- новый IP уже должен быть куплен/привязан к VPS у хостинг-провайдера.

## Установка

```bash
sudo apt update
sudo apt install -y curl python3

git clone https://github.com/dagmagnat/safe-vps-ip-switch.git
cd safe-vps-ip-switch
sudo ./install.sh
```

Установщик создаст короткую системную команду:

```bash
zamenaip
```

Она доступна из любого каталога. Сам скрипт устанавливается в `/usr/local/lib/safe-vps-ip-switch/`, а `/usr/local/bin/zamenaip` создаётся как символьная ссылка.

## Быстрый запуск

Для безопасной интерактивной замены IP достаточно:

```bash
sudo zamenaip
```

Команда сразу покажет текущий публичный IP, интерфейс и шлюз, затем спросит новый IP и проведёт все проверки/backup.

## Посмотреть текущую сеть

```bash
zamenaip status
```

Пример:

```text
Public IPv4 : 194.87.133.17
Interface   : eth0
Route source: 194.87.133.17
Gateway     : 194.87.133.1
```

## Безопасно поменять IP

```bash
sudo zamenaip
```

Пример диалога:

```text
Current network
  Public IPv4 : 194.87.133.17
  Interface   : eth0
  Gateway     : 194.87.133.1

New public IPv4: 5.42.120.63
Gateway [5.42.120.1]:
```

Если нужно сразу проверить сайт:

```bash
sudo zamenaip --domain hasdgu.ru
```

Можно передать все параметры сразу:

```bash
sudo zamenaip \
  --new-ip 5.42.120.63 \
  --prefix 24 \
  --gateway 5.42.120.1 \
  --domain hasdgu.ru
```

## Резервные копии

Перед изменениями создаётся каталог:

```text
/root/safe-vps-ip-switch-backups/YYYYMMDD-HHMMSS/
```

В нём сохраняются Netplan, nginx и снимки текущих маршрутов/адресов.

## Netplan

Скрипт создаёт отдельный файл:

```text
/etc/netplan/99-safe-vps-ip-switch.yaml
```

Существующие `50-cloud-init.yaml` и другие файлы не переписываются напрямую.

Для применения используется:

```bash
netplan try --timeout 120
```

Во время этого шага **не закрывай SSH**. Подтверждай конфигурацию только если соединение продолжает работать.

## После перезагрузки

Сначала перезагрузи VPS, пока старый IP ещё не удалён у провайдера:

```bash
sudo reboot
```

Подключись уже по новому IP и выполни:

```bash
sudo zamenaip verify
```

Если проверка успешна, старый IP можно сначала **отвязать** в панели хостинга. После этого ещё раз проверить SSH и сайт. Только затем старый IP можно окончательно удалить/освободить.

## Откат

Откат к последней резервной копии:

```bash
sudo zamenaip rollback
```

Или к конкретной:

```bash
sudo zamenaip rollback /root/safe-vps-ip-switch-backups/20261005-120000
```

## nginx

Скрипт не меняет `proxy_pass` и не пытается сам угадывать backend.

Но если в активной конфигурации уже есть:

```nginx
proxy_bind 194.87.133.17;
```

то при смене IP эта строка станет:

```nginx
proxy_bind NEW_IP;
```

После этого выполняется `nginx -t` и reload.

Если nginx вообще нельзя трогать:

```bash
sudo zamenaip --skip-nginx
```

## Важно

Скрипт меняет только сеть внутри Linux. Он не использует API Timeweb Cloud и не может купить, привязать или удалить IP у провайдера.

Новый IP сначала нужно привязать к VPS в панели хостинга. Старый IP удалять только после успешного reboot + `verify`.

## Обновление

После `git pull` снова запусти установщик:

```bash
sudo ./install.sh
```

Он безопасно заменит установленную копию, команда `zamenaip` останется прежней.

## Удаление программы

```bash
sudo ./uninstall.sh
```

Удаляются только установленный скрипт и команда `zamenaip`. Backup, журнал, state и активный Netplan-файл намеренно не удаляются автоматически.
