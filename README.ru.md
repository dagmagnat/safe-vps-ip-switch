# ZAMENAIP — безопасная смена основного IPv4 на VPS

[English README](README.md)

Краткая памятка для сотрудника: [docs/OPERATOR-GUIDE.ru.md](docs/OPERATOR-GUIDE.ru.md)

`ZAMENAIP` — интерактивный Bash-инструмент для безопасной смены основного IPv4 на Ubuntu-серверах с Netplan. Он рассчитан на ситуацию, когда оператор может не помнить сетевые команды и должен пройти процесс по понятному меню.

После установки достаточно выполнить:

```bash
sudo zamenaip
```

При первом запуске программа предлагает выбрать **Русский** или **English**. Выбор сохраняется, а язык можно изменить позже через меню настроек.

## Что есть в меню

```text
ZAMENAIP - Safe VPS IPv4 Switch

Текущий внешний IPv4: 5.42.120.63    Интерфейс: eth0

  1) Состояние IP и диагностика
  2) Заменить основной IPv4
  3) Проверка после замены / reboot
  4) Резервные копии и восстановление
  5) Проверить сайт и DNS
  6) Настройки / язык
  7) Справка оператору
  0) Выход
```

Во вложенных меню `0` всегда означает **Назад**.

## Основные возможности

- выбор языка при первом запуске: русский или английский;
- сохранение языка и домена для последующих запусков;
- показ текущего внешнего IPv4, интерфейса, gateway и маршрутов;
- список всех IPv4, которые Linux уже видит на сервере;
- проверка выхода в интернет отдельно с каждого локального IPv4;
- выбор нового IPv4 из списка или ручной ввод;
- временное добавление вручную введённого IP только для проверки;
- безопасная проверка нового IP и gateway **до изменения постоянной сети**;
- автоматическое предложение gateway из подсети, например `5.42.120.63/24 -> 5.42.120.1`;
- резервная копия Netplan, nginx, IP-адресов и маршрутов перед изменениями;
- применение сети через `netplan try --timeout 120`;
- проверка, что новый IP действительно стал внешним и основным исходящим;
- безопасное обновление точных `proxy_bind OLD_IP;` и `listen OLD_IP:PORT` в активных nginx-конфигах;
- `nginx -t` перед reload;
- проверка сайта локально и через публичный DNS;
- подсказка, на какой IPv4 должна указывать DNS A-запись;
- проверка после перезагрузки;
- список резервных копий и восстановление через меню;
- страховочный backup перед каждым restore;
- подтверждение перед reboot;
- журнал `/var/log/safe-vps-ip-switch.log`.

## Важное ограничение

Программа универсальная и не использует API конкретного хостинг-провайдера. Поэтому она может автоматически показать IPv4, **которые уже настроены в Linux**, но не может узнать адрес, который существует только в панели Timeweb/другого провайдера и ещё не добавлен в ОС.

В таком случае оператор выбирает **«Ввести новый IPv4 вручную»**. Скрипт временно добавляет адрес и проверяет, действительно ли с него можно выйти в интернет.

Аналогично программа не меняет DNS-записи у регистратора автоматически без API конкретного DNS-провайдера. Она проверяет DNS и показывает, какой A-адрес нужно установить.

## Установка

```bash
git clone https://github.com/dagmagnat/safe-vps-ip-switch.git
cd safe-vps-ip-switch
sudo ./install.sh
```

Установщик:

- проверит необходимые зависимости;
- при необходимости установит их через `apt-get`;
- установит программу в `/usr/local/lib/safe-vps-ip-switch/`;
- создаст короткую команду `/usr/local/bin/zamenaip`;
- предложит запустить программу сразу.

Если запускать меню сразу после установки не нужно:

```bash
sudo ./install.sh --no-start
```

Дальше из любого каталога:

```bash
sudo zamenaip
```

## Типовой сценарий для сотрудника

1. В панели хостинга привязать новый IPv4 к VPS, но старый пока не удалять.
2. Подключиться к серверу по SSH.
3. Выполнить:

```bash
sudo zamenaip
```

4. Выбрать `1` и проверить текущее состояние.
5. Выбрать `2` — **Заменить основной IPv4**.
6. Выбрать новый IP из списка. Если его нет — выбрать ручной ввод.
7. Дождаться проверки нового IP и gateway.
8. Подтвердить создание backup и запуск `netplan try`.
9. Не закрывать SSH, пока Netplan не попросит подтвердить новую конфигурацию.
10. Проверить сайт/DNS.
11. Перезагрузить сервер по предложению программы или вручную.
12. После reboot снова выполнить `sudo zamenaip` и пункт `3`.
13. Только после успешной проверки сначала **отвязать** старый IP у провайдера.
14. Проверить сервер ещё раз и только после этого удалять/освобождать старый IP окончательно.

## Резервные копии

Backup создаётся автоматически перед сменой сети. Также его можно создать вручную:

```bash
sudo zamenaip backup
```

По умолчанию копии хранятся в:

```text
/var/backups/safe-vps-ip-switch/
```

В backup входят:

- `/etc/netplan`;
- `/etc/nginx` (если установлен);
- `ip addr`;
- все маршруты;
- результат `netplan get`;
- метаданные текущей сети.

Восстановление удобнее запускать из меню:

```bash
sudo zamenaip
```

Пункт `4` → **Резервные копии и восстановление**.

Перед restore программа создаёт ещё одну страховочную копию текущего состояния.

## Быстрые команды для опытного администратора

```bash
sudo zamenaip              # главное меню
sudo zamenaip switch       # сразу мастер смены IP
sudo zamenaip verify       # проверка последней замены
sudo zamenaip backup       # создать backup
sudo zamenaip rollback     # меню восстановления
sudo zamenaip language     # изменить язык
sudo zamenaip status       # состояние сети
zamenaip --version
```

## Где хранятся данные

```text
/etc/safe-vps-ip-switch.conf          язык, домен, DNS-настройки
/etc/netplan/99-zamenaip.yaml         управляемый Netplan-файл
/var/lib/safe-vps-ip-switch/          состояние последней замены
/var/backups/safe-vps-ip-switch/      резервные копии
/var/log/safe-vps-ip-switch.log       журнал
/usr/local/bin/zamenaip               быстрая команда
```

## Поддерживаемые системы

Основной целевой вариант:

- Ubuntu 22.04 / 24.04;
- Netplan;
- systemd-networkd или стандартная серверная конфигурация Ubuntu;
- IPv4;
- nginx поддерживается дополнительно, но не обязателен.

Скрипт специально не пытается автоматически переписывать сетевую конфигурацию CentOS, AlmaLinux, Debian без Netplan, NetworkManager и панели конкретного облачного провайдера.

## Безопасность

Даже с `netplan try` сетевые изменения по SSH всегда несут риск. На критичных серверах желательно иметь доступ к web/VNC/serial console хостинг-провайдера.

`ZAMENAIP` **никогда сам не удаляет IP из панели хостинга**. Это сделано намеренно: окончательное удаление адреса должно происходить только после проверки после reboot.

## Удаление программы

```bash
sudo ./uninstall.sh
```

Удаляется исполняемый файл и команда `zamenaip`. Backup, журнал, настройки и Netplan-файл намеренно остаются на месте, чтобы удаление программы не сломало сеть.
